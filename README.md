## Hi there 👋

I'm **Gurpreet Singh**, a Software Engineer at [crossml](https://crossml.com) in Chandigarh, India.

> **4+ years shipping production full-stack software — with AI built in, not bolted on.**

I build products end to end: Next.js frontends, Django/Node backends, the agents and MCP servers that give LLMs real tools, and the OCR/NLP pipelines behind them — deployed on AWS and GCP.

### 🔭 What I'm building

- **AI agents & MCP servers** — tool servers that let LLMs act on real systems: [Shopify MCP](https://github.com/Gurpreet-CrossML/store-signals-ai-shopify-mcp), [Magento MCP](https://github.com/Gurpreet-CrossML/store-signals-ai-magento-mcp), [WhatsApp bot MCP](https://github.com/Gurpreet-CrossML/gustavo-whatsapp-bot-mcp)
- **E-commerce intelligence** — [Store Signals AI](https://github.com/Gurpreet-CrossML/store-signal-ai-frontend-nextjs), a Next.js frontend over AI-driven store analytics
- **Workflow automation** — [AI lead automation](https://github.com/Gurpreet-CrossML/ai-lead-automation-workflow) with n8n and LLMs
- **OCR & NLP pipelines** — document extraction and text-processing services in Python
- **Product apps** — [mate-check](https://github.com/Gurpreet-CrossML/mate-check) (web, [app](https://github.com/Gurpreet-CrossML/mate-check-app), [backend](https://github.com/Gurpreet-CrossML/mate-check-backend)), [meato](https://github.com/Gurpreet-CrossML/meato) — a butcher delivery site with an AI meat assistant
